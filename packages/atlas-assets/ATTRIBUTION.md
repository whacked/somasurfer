## Share-alike obligations

The following assets carry a share-alike obligation:

- BD body template, BodyParts3D 4.0 adult — CC-BY-SA-4.0
- ALC-1 name index and structure coverings — CC-BY-SA-4.0

That obligation is confined to this package by the following, checked on
every push by `tools/check-licence-separation.mjs`:

1. No code package declares a dependency on `@gstack/atlas-assets`.
2. No code package imports from it.
3. The asset package is outside the npm workspace list, so it is never
   linked into `node_modules` where an import could resolve by accident.
4. No asset bytes are embedded in the shipped JavaScript or CSS bundle.
   Assets are emitted as separate files under `dist/assets/`, which
   carries this file and the asset `LICENSE` alongside them.

See `packages/atlas-assets/LICENSE` and the repository-root `LICENSE`.
